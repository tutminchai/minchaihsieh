Privacy notice

This site uses a private analytics service for website administration, recording IP addresses, visit times, pages, approximate countries, devices and visit counts. A random browser ID estimates unique visitors; it does not reveal your name. GPS, message contents and URL search parameters are not collected.

Data is processed using Supabase and is accessible only to the site owner. Full IP addresses are encrypted. Existing records and totals are retained without automatic expiry.
